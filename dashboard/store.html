FAQ

What API keys do I need? ▼
All templates require an Anthropic API key (Claude AI). The Research Agent also needs a free NewsAPI key. The Job Search Agent works with zero additional keys — job APIs are 100% free.
How much does the Claude API cost? ▼
Claude Sonnet 4 costs ~$3 per million input tokens and ~$15 per million output tokens. A typical blog post generation costs about $0.01-0.03. Job scoring costs even less. Most users spend under $5/month.
Can I modify and resell these? ▼
You can modify the code for your own use and build products on top of it. You cannot directly resell the template code as-is. See the license for details.
Do I need Python experience? ▼
Basic Python knowledge helps for customization, but the default setup works out of the box. Just install dependencies and add your API key — the README walks you through every step.
What Python version do I need? ▼
Python 3.9 or higher. Tested on 3.9, 3.10, 3.11, and 3.12. Works on macOS, Linux, and Windows.
